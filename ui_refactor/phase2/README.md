## 一分钟结论

1. **“桥下基地”不是现工程事实。** 基地是南墙内侧的开放圆形平台，中心 `(0,0.16,-98)`、半径 7m，平台南缘距墙内面约 0.3m；工程中没有桥、高架、二层室内或章节系统。
2. **“地下 B1”是事实。** 坡道从公园 `z=12.6` 下到 `z=-8.2`，B1 在 `y=-14`，3 个核心台，出口只有一条坡道，无传送。
3. **“旧城区高架交通维护楼二层观察室”按字面不成立。** 无高架；二层 7.2m 视线会被 5.2m 南墙截断。它只能作为**菜单专用新布景**候选，不能写成正史。
4. **首选 O3：南墙外侧维护观察室。** 房间中心约 `(12,7.2,-109.25)`，相机视高 8.8m、24mm；到基地中心的视线在墙顶上方约 **0.445m** 通过。基地近端被墙遮挡，属于可接受前景。它是菜单专用，不进可玩地图。
5. **正史安全回退 O5：** 不建新建筑，直接把固定相机放在现有南墙/基地轴线上。叙事弱，但零新增地理。
6. **CG 制作走“白模 → 锁构图 → 模块资产 → 灯光 → 分层渲染 → Godot 集成”，不先做高模。** 交付无文字纯净背景；UI 安全区、裁切、色彩、回退写入 D 契约。
7. **阶段一审计保留。** CG 是新增视觉层，不是跳过布局/焦点/状态真实的理由；本轮没有改任何生产代码。
8. **新概念图按参考处理，不按资产处理。** E-07/高架/列车在现工程仍无依据；图上的标题、菜单、页脚都是烘焙文字，最终必须由 UI 层重做。拆解与可交互原型见 [E](concept/E_概念图拆解与菜单UI设计.md)。

## 证据等级

沿用阶段一：

- `STATIC_VERIFIED`：直接来自源码/常量，可复读；
- `HARNESS_VERIFIED`：工程脚本实际运行/测量；
- `UNVERIFIED`：尚未运行或无法从代码确认；
- `NOT FOUND`：工程范围内检索不到；
- `DESIGN HYPOTHESIS`：本轮提出的设计判断，需评审。

本轮的关键事实（基地/B1/坡道/墙/无桥/无章节）是 `STATIC_VERIFIED` 或 `NOT FOUND`；O3 的相机/构图/工时是 `DESIGN HYPOTHESIS`；所有实机效果、手柄、4 人联机、显存、4K 显示均为 `UNVERIFIED`。

## 工具

`tools/dump_layout.gd` 用于导出某个种子的 `CityLayout` 快照：

```bash
godot --headless --path . \
  --script res://ui_refactor/phase2/tools/dump_layout.gd \
  -- --seed=4242
```

输出：`ui_refactor/phase2/tools/layout_4242.json`。  
说明：

- 该脚本只读 `CityLayout.generate()`，不启动游戏、不写生产工程；
- 快照只代表该种子，不代表所有随机城市；
- 本轮的结论主要依赖工程常量，不依赖该快照；
- 如果 Godot 可执行文件不在 PATH，请替换为实际路径；本轮未重新执行该命令。
