# F · 设计系统（UI v3）

- 代码基准：`edd19c1`
- 入口：`scripts/ui_theme.gd`（`DeadCityUI`）、`scripts/ui_settings.gd`
- 适用：主菜单、联机大厅、军械库、战斗 HUD、背包、情报、抽卡、暂停、结算

## 1. 语义色

| Token | 值 | 用途 |
|---|---|---|
| `BG` | `#08090a` | 全局底色、遮罩基础 |
| `PANEL` | `#101315` | 主面板 |
| `PANEL_SOFT` | `#171b1d` | 次级面板 |
| `PANEL_RAISED` | `#1d2123` | 抬升面板 |
| `LINE` / `LINE_SOFT` | `#2b2f30` / `#202425` | 分隔线、边框 |
| `TEXT` | `#f3ede3` | 主文字（暖白） |
| `MUTED` | `#b6aa99` | 次级文字 |
| `MUTED_2` | `#968b7d` | 弱化文字 |
| `CYAN` | `#7fc3ba` | 安全区、友方、冷静状态 |
| `AMBER` | `#e6a75e` | 焦点、选择、可交互 |
| `AMBER_DIM` | `#8f6b3f` | 弱化琥珀（对比度不足，仅装饰） |
| `RED` | `#e06b5a` | 危险、失败 |
| `GREEN` | `#9bc284` | 稳定、成功 |
| `VIOLET` / `CORAL` | `#b9a6d9` / `#e08a6f` | 队友 3/4 |
| `ZOMBIE` | `#9aad72` | 感染者标记 |

规则：

- 颜色只承担语义，不承担唯一编码；状态必须同时有文字、形状或位置。
- 高对比模式：`text_color()` 提亮 12%，HUD 文字描边 3px；菜单背景开启对比层。
- `AMBER_DIM` 在面板上实测约 3.86:1，不得用于正文。

## 2. 字体与排版

- UI 字体：`Microsoft YaHei UI → Microsoft YaHei → Noto Sans CJK SC → Source Han Sans SC → Arial`。
- 标题衬线：`Source Han Serif SC → Noto Serif CJK SC → STSong → SimSun → Songti SC → Georgia`。
- 等宽：`Cascadia Mono → Consolas → Noto Sans Mono CJK SC → monospace`。
- 全部通过 `SystemFont` 加载，不随包分发字体文件；发行前需确认目标系统字体许可与可用性。
- 层级：
  - 主标题 64px（菜单品牌）/ 34px（大厅）；
  - 页面标题 25–32px；
  - 分区标题 18–21px；
  - 正文 13–15px；
  - 辅助信息 10–12px；
  - HUD 数字 26–30px，状态 9–11px。
- 中文行距默认由字体决定；长文本使用 `AUTOWRAP_WORD_SMART`。未做伪本地化/系统字体缩放测试。

## 3. 布局与安全区

- 基准 1280×720，`canvas_items` + `expand`；逻辑尺寸 = 窗口 / 缩放。
- 主菜单：外边距 62/34/62/26，左列伸缩比 1.35，右列最小 352；背景 16:9 概念图，左暗右亮。
- HUD：
  - 顶部全宽渐变遮罩 250px；底部左右渐变遮罩 560/460×330；左上对角遮罩 430×370。
  - 小队面板：`(20,152,284,auto)`，内容边距 12/8/12/10，半透明底 `rgba(0.018,0.023,0.026,0.68)`。
  - 生命：左下 `(30,-86,248,66)`；弹药：右下 `(-298,-92,268,72)`；小地图：`(-216,20,188,188)`。
  - 交互提示：底部居中 `(-240,-124,480,24)`。
- 安全区：主菜单文字集中在左侧约 38% 宽度；关键内容不进入右缘/下缘 24px；2560×1080 下背景按 `KEEP_ASPECT_COVERED` 裁切，需单独检查构图。
- 高 DPI：以物理窗口放大保持 1280×720 逻辑视口；UI 放大 150% 在 720p 窗口会出现菜单项越界（已知 warning）。

## 4. 组件与状态

| 组件 | 规范 |
|---|---|
| `MenuNavItem` | 主项 58px / 次项 44px；琥珀左括号 + 位置/亮度表达焦点；禁用透明度 0.72 |
| 菜单子界面 | 右侧/居中面板，`panel_style` 圆角 3，边框 1px，内容边距 30/26 |
| 按钮 | 正常/悬停/按下/禁用；焦点为 2px 琥珀描边；不用大色块 |
| 小队行 | 名称 + 生命条 + 状态文字；倒地/断线/距离提升优先级 |
| 生命 | 数字 + 细条；稳定/受伤/危险/失去意识四态；低血不用持续红闪 |
| 弹药 | 当前武器、弹匣/备弹、换弹/空仓/近战/搬运状态；搬运时禁止开火 |
| 小地图 | 188×188；友方/目标/威胁用形状+颜色双编码 |
| 覆盖层 | 情报/背包/抽卡/暂停/结算统一深色底 + 细边框；打开时释放输入，关闭恢复 |
| 设置 | HUD 缩放 90/100/110%、高对比、减少动效、音量/画面；写入 `user://ui_settings.cfg` |

状态矩阵必须覆盖：默认、悬停、键盘/手柄焦点、按下、禁用、等待、成功、失败、隐藏、恢复。当前自动化覆盖默认/焦点/按下/禁用/打开/关闭/输入恢复；手柄焦点未测。

## 5. 动效

- 菜单导航选中：0.16s（减少动效 0.001s）。
- 子界面横向进入：0.18s，`TRANS_QUAD` + `EASE_OUT`。
- 浮尘：36 个 GPUParticles2D，加法混合；菜单隐藏时停止。
- 视差：鼠标 ±0.010/±0.006，lerp 速率 3.2；减少动效归零。
- 暖光呼吸：±0.06 alpha，0.42 rad/s；减少动效固定。
- 规则：动画可打断；重复触发不堆 Tween；不做延迟输入；覆盖层打开时停止背景粒子/重绘。

## 6. 无障碍

- 目标：正文 4.5:1，大字/关键图形 3:1；实际渲染像素审计结果见 `E_验证报告.md`。
- 已实现：HUD 90/100/110%、高对比描边、减少动效、焦点可见、形状+颜色双编码、无持续强闪。
- 已知不足：14 项小字/瞬时横幅低于 4.5:1；菜单 UI 放大 125/150% 在 720p 窗口有越界 warning；未做色觉模拟截图与屏幕阅读器测试。
- 不建议：仅靠红/绿区分状态；用大面积霓虹/扫描线；用假进度条。
