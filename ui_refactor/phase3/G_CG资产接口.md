# G · 主菜单 CG 资产接口

- 代码基准：`edd19c1`
- 当前实现：`scripts/menu_backdrop.gd`
- 背景资源：`assets/ui/menu/e07_observation_exterior.webp`（1672×941，概念图占位）
- 目标：未来替换 Blender CG 时，**只换背景资源，不改菜单布局与交互**。

| 项 | 值 |

## 2. 菜单安全区

- 布局：左侧文字列约占宽 38%，右侧为场景主体；外边距 62/34/62/26。
- 1280×720 / 1920×1080 / 1920×1200：文字不进入右缘 24px、下缘 24px。
- 2560×1080（21:9）：背景左右裁切；主视觉（观察窗/室内主体）必须落在中央 16:9 安全区内。
- 可读性：左侧文字区应有稳定的暗部/压暗层；右侧高光不得压过标题与导航。
- 禁止：把菜单文字、按钮、商标或 UI 烘焙进背景图。

## 3. 未来 Blender 交付规格

- 分辨率：至少 3840×2160；若必须覆盖 2560×1080，建议 5120×2160 或提供独立宽屏构图。
- 格式：PNG/EXR 无损；sRGB 色彩空间；不带 alpha 也可；分层渲染时提供合成后 clean plate。
- 内容：纯净背景，无文字、无按钮、无 HUD、无菜单暗角（暗角由运行时叠加）。
- 构图：固定相机、35mm 左右；近景/中景/远景分层；主视觉位于中央安全区。
- 分层：建筑、室内、道具、植被、雾/尘、灯光可独立编辑；保留 `.blend` 工程。
- 风格：与低多边形游戏世界协调；不直接复制《最后生还者》的窗型、室内布置或构图。
- 授权：交付时附来源、许可、是否 AI 生成、可商用范围。

## 4. 运行时接口

- 替换方式：只替换 `TEXTURE_PATH` 指向的文件；`MenuBackdrop` 通过 `TextureRect` + `STRETCH_KEEP_ASPECT_COVERED` 适配，不依赖固定尺寸。
- 视差：`ShaderMaterial` 仅对 UV 做 `parallax` 偏移；新背景需保留边缘余量（建议四周 ≥3% 可裁切）。
- 压暗/暖光/暗角/浮尘：运行时叠加，不烘焙进背景。
- 缺失回退：资源不存在时显示“E-07 背景资源缺失”占位，不崩溃。
- 减少动效：关闭视差与浮尘，背景仍保持静态可读。
- 高对比：菜单背景对比层可独立开关，不修改背景资源。

- [ ] 中央 16:9 安全区包含主视觉
- [ ] 左侧文字区有足够暗部，标题/导航可读
- [ ] 视差边缘无露底
- [ ] 减少动效/高对比下仍可用

## 6. 与 Abandoned_House 的关系

`Abandoned_House` 是独立的 3D 场景素材（房屋 + 街区 + 家具），**不是**主菜单 CG 背景，也不应直接替代 E-07 概念图。若未来要用它做关卡或菜单实拍，需要先完成网格合并、碰撞、家具筛选与授权确认，见 `assets/models/abandoned_house/README.md`。
