3. `Abandoned_House` 授权不明，725 网格/558m 碰撞地面未整理，不能直接进关卡。
4. 真实玩家、真实手柄、OS DPI、最低规格硬件均未验证；不得宣称可用性/性能已通过。
5. 故障网络长测结束的断连竞态会产生 `Node not found` 日志，虽不影响断言，但应清理。
