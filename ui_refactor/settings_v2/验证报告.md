| 操作 | 结果 |

| 分辨率 `1600x900` | `window_get_size() = (1600, 900)` |
| `render_scale=0.75` | 根 Viewport `scaling_3d_scale = 0.75` |
| `fps_limit=90` | `Engine.max_fps = 90` |
| 全部取消 | 恢复 1280×720 窗口 |

## 4. 真实参数接线

| 参数 | 代码路径 | 证据 |
|---|---|---|
| 水平/垂直灵敏度 | `player._apply_mouse_look` | 测试断言 yaw/pitch 变化 |
| 反转 Y | 同上 | pitch 方向断言 |
| ADS 倍率 | `player._apply_mouse_look` + `aiming` | yaw 差值断言 |
| FOV / ADS FOV | `player._update_visuals` → `_camera.fov` | 90/60 断言 |
| 瞄准按住/切换 | `player._unhandled_input` + `_physics_process` | 两次切换进入/退出 ADS |
| 窗口/分辨率/VSync/帧率/渲染比例 | `UISettings._apply_display` | 非无头探针 |
| 音量 | Master/SFX/UI Bus | Bus 音量/静音断言 |
| HUD/准星/小地图/任务提示/受伤反馈 | `game_hud._apply_settings` | UI 测试断言 |
| 键位 | `InputMap` + player/main action 调用 | 跳跃、情报实际触发 |

## 5. 未验证 / 已知限制

1. **真实手柄硬件**：未接入、未测试，不声明支持。
2. **真实玩家可用性测试**：未执行；没有 5–8 人任务数据。
3. **OS 级 125%/150% 缩放**：只做了窗口/内容缩放的等效检查，未修改 Windows 显示缩放。
4. **最低规格硬件**：只在 RTX 4060 Laptop 上测。
5. **显示异常回退**：10 秒超时逻辑有自动化测试，但没有在真实黑屏/显示器切换故障上演练。
6. **音乐/环境音/语音**：工程没有对应资源与 Bus，未提供滑块。
7. **蹲伏/镜头晃动**：玩法没有蹲伏，镜头晃动没有独立控制器，未提供无效设置。
8. **阴影/抗锯齿/后处理**：未接入可安全运行时切换的渲染路径。
9. **字幕**：没有字幕系统。
10. **HUD 背景浓度**：只作用于 HUD 边缘防背光渐变，不覆盖中央战斗视野，也不改变文字亮度。
11. **真实 WAN**：设置页与联机行为只在 localhost 测试。
12. **截图分辨率**：2560×1080 下中栏会保留较宽留白，这是宽屏布局结果，不是裁切。
